Walawe Minecraft

Vanilla Java Edition 1.21.11 — Survival — 10 Players

mc.walawe.fun

Requirements

  • Minecraft Java Edition 1.21.11
  • A paid Minecraft account (online-mode is on)
  • The Modflared mod installed

Step 1 — Install Modflared

Modflared is a client mod that lets you connect to Cloudflare-tunneled servers. You only need to install it once.

Download Modflared from: modrinth.com/mod/modflared

If you use a modded launcher (Prism, ATLauncher, etc.):

  • Download the Modflared .jar file from the link above
  • Drop it into your instance's mods/ folder
  • Make sure you have Fabric or Forge (check Modflared's page for which loader it requires)

If you use the official Minecraft launcher:

  • You'll need to create a modded profile — consider using Modrinth App or Prism Launcher instead, they make modding much easier
  • Both are free and support dragging & dropping mod files into your game

Step 2 — Add the Server

1

Open Minecraft with the Modflared mod loaded

You should see Modflared in the bottom-left corner of the main menu if it's installed correctly

2

Go to Multiplayer → Add Server

3

Paste mc.walawe.fun as the server address

4

Click Done, then Join Server

Modflared handles the Cloudflare tunnel automatically — no terminal or extra config needed

Troubleshooting

  • Can't connect? — Make sure Modflared is actually installed. Check the mods folder or look for it on the main menu
  • Wrong version? — Everyone must run exactly 1.21.11. Newer clients can't join an older server
  • TLauncher / cracked client? — This server requires a paid account. Free/cracked clients won't work
  • Modflared not showing up? — Make sure you downloaded the version matching your mod loader (Fabric / Forge) and Minecraft version
